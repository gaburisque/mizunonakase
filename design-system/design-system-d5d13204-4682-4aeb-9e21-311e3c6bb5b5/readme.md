# 株式会社水のナカセ — デザインシステム

水中ポンプのレンタル・販売・修理を行う **株式会社水のナカセ**（nakase）のホームページ制作用デザインシステム。
日本語のコーポレートサイトを、誰が組んでも同じ品位で作れるようにするための、トークン・コンポーネント・UI キット一式です。

## 2. ブランドの理解

- **事業**：水中ポンプのレンタル（汚水用・残水用・大水量）、付帯機材（発電機・ホース）、修理・メンテナンス。
- **顧客**：土木・建築・設備の工事会社、プラント、自治体。決裁者は現場代理人や資材担当で、**「今日中に届くか」「この揚程で足りるか」** が判断軸。
- **一番の強み（訴求の芯）**：**河川工事や仮排水の現場に必要な機材を、計画から設置までワンストップでサポートできること**。機材の貸し出しだけでなく、排水計画のご相談 → 機種選定 → 配管・発電機まで含めた一式の手配 → 現場での据付・撤去まで、窓口ひとつで通す。この一文がサイト全体の主張であり、ヒーロー・製品一覧・ご利用の流れ・お問い合わせのすべてで言い換えながら繰り返す。
- **訴求しないこと**：保有台数・出荷件数などの規模の数字は売りにしない（在庫量で勝負する会社ではない）。**具体的なレンタル料金もサイトに掲載しない** — 機種・台数・工期・配管・地域で変わるため、必ず「お見積もり」に寄せる。在庫ラベル（在庫あり／残りわずか）も使わない。
- **書いてはいけないこと**：即日対応・最短当日・最安・地域最大などの根拠のない表現、未確認の実績・資格・在庫数。関連機材を「常時在庫」と書かない（案件に応じて手配する）。水理計算・流量測定を「無料」と断定しない（範囲が未確認）。搬入・設置を「必ず対応します」と書かない（案件により範囲が異なる）。
- **対応エリア**：北海道全域。旭川の拠点を起点に道内の現場へ届ける。
- 内容設計の全体像は `docs/site-content-plan.md`（サイトマップ・各ページの掲載内容・コピー案・必要素材・確認事項）。原稿を書く前に必ず読む。
- **ロゴ**：水しぶきが風車状に回るマーク（ブルー）＋ `nakase` の小文字ワードマーク（黒）。マークは「動いている水」を表す唯一のブランド資産で、**描き起こし・再構成は禁止**。拡大して薄く敷く「透かし」だけが許された加工です。

## 3. コンテンツの基本（CONTENT FUNDAMENTALS）

**声のトーン**：現場の担当者に、落ち着いた敬体で話しかける。感情表現は使わず、条件と数字で語る。

- **人称**：自社は「当社」（社名を出す場合は「ナカセ」）。相手は「御社」「お客様」。「私たち」は使わない。
- **文体**：敬体（です・ます）で統一。体言止めは見出しのみ。命令形（「今すぐ〜しよう」）は使わない。
- **見出し**：短い言い切り。句点は付けないか、リズムを作る場合のみ 1 つ。
  - 良い例：「水中ポンプは水のナカセ。」「機材を貸すだけでは終わりません。」「計画から設置まで、窓口はひとつ。」
  - 悪い例：「お客様の課題を解決するトータルソリューション」（抽象語・カタカナ複合）
- **リード文**：60〜100 字。強みの一文（計画から設置までワンストップ）に必ず触れる。例：「河川工事や仮排水の現場に必要な機材を、計画から設置までワンストップでサポートします。」
- **数字の使い方**：口径・吐出量・全揚程といった**仕様の数字は積極的に**出す。一方で保有台数・出荷件数・料金は出さない。
- **CTA の文言**：動詞で終える。「無料で見積もりを依頼」「計画から相談する」「この機種で見積もる」。「詳しくはこちら」は使わない。
- **料金の書き方**：金額は書かず、「レンタル料金はお見積もり」「一式でご提示します」と、その理由（工期・台数・配管・地域で変わる）を添える。
- **数字・単位**：半角。単位は半角スペースを挟む（`0.35 m³/min`、`12 m`、`80mm` は口径表記のみ詰める）。金額は `¥2,800`、期間は「30 日以上」。
- **英字のアイブロウ**：セクション上の小見出しに `RENTAL LINEUP` `HOW IT WORKS` `FAQ` のような英大文字を使う（装飾であり、意味は日本語の見出しが持つ）。
- **注記**：「※」で始め、12px・グレー。誇張の打ち消し（「※ 在庫状況は目安です」）は必ず添える。
- **絵文字**：使わない。顔文字・記号の装飾も使わない。
- **禁止語彙**：「業界No.1」「圧倒的」「革新的」「ソリューション」「ワンストップ」など、裏付けのない誇張とカタカナ抽象語。

## 4. ビジュアルの基本（VISUAL FOUNDATIONS）

### 色
- 地は **純白**（`--surface-canvas`）。交互バンドに **ミスト**（`--surface-mist` #f5f8fa）、表ヘッダーに **フォグ**（#eef3f7）、締めに **濃紺**（`--surface-slab` #14212c）。地色はこの 5 面だけで、これ以外は作らない。
- 有彩色は **ブルー 1 系統のみ**。ロゴのブルー `#55b2eb`（`--blue-400`）はマーク・濃色面のアクセント・電話番号に使い、白地の上の CTA とリンクは可読性のため **`--blue-700` #0f72af**（白文字とのコントラスト 5.2:1）を使う。
- ブルーは **1 画面に 2 か所まで**（主 CTA ＋ 見出しの罫、など）。カード内の副次ボタンは黒枠（`outline-ink`）に落とす。濃色面の上では主 CTA が `on-slab`、副次が `outline-slab`（白枠）。
- ステータス色（緑・橙・赤）は在庫・注意・エラーの表示専用。装飾には使わない。
- 階層は**不透明度で作らない**。`--text-muted` / `--text-faint` に色を切り替える。

### 書体
- 見出し＝**Zen Kaku Gothic New 700**、本文＝**Noto Sans JP 400/500**、数値・型番・電話番号＝**Roboto Mono**。すべて Google Fonts（差し替え容易）。
- 和文の可読性を最優先：本文 **行間 1.9・字間 0.04em・1 行 40〜45 字**。見出しは行間 1.32〜1.45。
  （参考 DESIGN.md の「見出し行間 1.0」は欧文前提のため、和文では採用していません。）
- ボタンは大文字変換しない（和文のため）。字間 0.08em で密度を抜く。
- 最小サイズは 12px。仕様表・注記は 14px / 12px。

### 形・影
- **角の二段構え**：ボタン・入力は **6px**、カード・写真枠は **16px**。この差がブランドの手触り。ピル（9999px）は絞り込みチップ専用。
- 影は 3 段（`lift` / `raise` / `modal`）。使うのは基本 **lift だけ**。段差は影ではなく **面の色差**（白カード on ミストバンド）で作る。
- 罫線は 1px `--border-hairline`。強調したい枠だけ `--border-strong`。

### 背景・イメージ
- グラデーション、パターン、テクスチャは**使わない**。
- 唯一の装飾は **マークの透かし**：濃色 CTA バンドやヒーローの端に、ロゴマークを opacity .05〜.08 で大きく（幅 400px 前後）はみ出させて敷く。
- 写真は **16:9 / 4:3 / 1:1** を 16px 角丸の枠に収める。丸マスクは使わない。トーンは**実写・自然光・寒色寄り・加工なし**（北海道の現場写真の生々しさをそのまま使う）。フィルタ・彩度調整はしない。
- **現場写真は `fit="cover"`**、**白抜きのポンプ単体写真は `fit="contain"`**（白地の上に置き、機材のシルエットを切らない）。
- 写真の上に文字を乗せるときは、**左から濃紺（#14212c）0.90 → 0.15 の横方向グラデーション**を 1 枚重ね、文字は左半分に置く。写真自体は暗くしない。
- 支給写真（`assets/photos/`）：`site-channel-sunset.webp`（郊外・護岸築造／ヒーロー向きの引き）、`site-canal-crew.webp`（市街地の水路・作業員あり）、`site-urban-canal.webp`（市街地で 2 台並列運転）、`site-winter-hoses.webp`（冬期・配管の取り回し）、`pump-f-1660a.png` / `pump-krs-1022-51.png` / `pump-u-65014.png`（機材の白抜き）。

### 動き・状態
- 動きは短く直線的。**120ms（色）/ 180ms（開閉・ホバー）/ 320ms（せり上がり・ドロワー）**、イージングは `--ease-standard` / `--ease-out`。跳ね（bounce）・派手な拡大は使わない。
- 実装は `tokens/interactions.css`（`styles.css` から自動で読み込まれる）。**JS は不要** — スクロール連動は CSS の `animation-timeline: view()` で動く。
- **せり上がり（`.nk-reveal`）**：セクションの中身に付けると、画面に入る過程で 20px 下から立ち上がる。セクション単位でまとめて 1 回。要素ごとに刻まない。
- **読み込み時（`.nk-enter` ＋ `.nk-enter-1〜5`）**：ヒーローなど最初から見えている領域だけ。60ms 刻みで 5 段まで。
- **ヒーロー写真（`.nk-hero-photo`）**：26 秒かけて 1.06 → 1.13 倍へゆっくりドリフト（往復）。
- **締めの CTA**：ロゴマークの透かしが 90 秒で 1 回転する（水しぶきが回るマークの由来を動きで示す、唯一の遊び）。
- `prefers-reduced-motion: reduce` ではすべて無効化される。
- **ホバー**：塗りボタンは 1 段明るいブルー（`--blue-600`）、枠ボタンは背景に `--color-primary-faint`、カードは影 `lift → raise`。文字リンクは色を `--blue-600` へ。
- **プレス**：塗りボタンは `--blue-800`。縮小（transform）はしない。
- **フォーカス**：`--focus-ring`（淡いブルーの 3px リング）。キーボード操作を消さない。
- 透明度・ブラーは使わない（濃色面の白 12% 塗りのバッジのみ例外）。

### レイアウト
- コンテンツ幅 **1200px**、左右余白 24px。長文は 760px で折る。
- 縦のリズム：バンド間 **96px**（SP 56px）。ユーティリティ帯 36px、ヘッダー上段 76px＋ナビ下段 48px（1024px 未満はハンバーガー）、フッター上下 64px。
- グリッド：製品カード 3 列（〜1200px で 2 列、768px 未満で 1 列）、料金 3 列、フッター 5 列。
- ページの並びは固定：**ユーティリティ帯 → ヘッダー → 白ヒーロー → ミスト → 白 → ミスト → 濃色 CTA → 濃色フッター**。締めは必ず濃色。

## 5. アイコン（ICONOGRAPHY）

- 支給素材に**アイコンセットは含まれていません**。アイコンフォント・スプライト・SVG のいずれも存在しないため、**Lucide（CDN, v0.474.0）を線幅 1.75 で暫定採用**しています。→ **要ご確認・差し替え候補**
- 塗りアイコンは使わず、線のみ。サイズは 18 / 20 / 24 / 32px。色は `currentColor`、特徴カードでは淡いブルーの角丸（10px）四角に収める。
- よく使う名前：`droplets`（水）`truck`（配送）`phone`（電話）`wrench`（整備）`clock`（受付時間）`map-pin`（エリア）`file-text`（資料）`shield-check`（保証）。
- **絵文字は使いません。** Unicode 記号は「※」「›」（パンくずの区切り）「・」（箇条書き）のみ。
- ロゴマークはアイコンとして流用しない（透かしとロゴ表示のみ）。
- 実装は `components/core/Icon.jsx`（`window.lucide` に依存）。ページ側で CDN スクリプトを読み込むこと。

## 7. 未確定事項・ご確認いただきたいこと

1. **写真**：現場写真 4 点・機材写真 3 点をいただき、ヒーロー／事例／機種カード／詳細に反映しました。事例の会社名・工事名は仮のままです（実名で掲載可能な案件をお知らせください）。
2. **アイコン**：Lucide での代替。指定のアイコンセットがあれば差し替えます。
3. **書体**：Google Fonts から Zen Kaku Gothic New ＋ Noto Sans JP を選定。既に使用中の指定書体があればお知らせください。
4. **実データ**：社名・機材の型番と写真以外（電話番号・住所・仕様値・事例の工事名）は仮の値です。料金は方針どおり非掲載にしています。
5. **アクセント色**：ロゴのブルー `#55b2eb` は白地の小さな文字では可読性が足りないため、CTA・リンクには濃いブルー `#0f72af` を併用しています。この二段運用でよいかご確認ください。
